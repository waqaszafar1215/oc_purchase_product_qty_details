ABS Purchase
Quantity

See ordered and received quantities directly on every purchase order line. Know exactly what arrived vs what was ordered without opening delivery receipts.

Odoo 17 · 18 · 19 Purchase Orders RFQs Zero Config

WITHOUT THIS MODULE

Checking receipts is slow

Procurement teams must open the receipt (stock picking) to compare received quantities against the purchase order. This context switching is slow, especially when managing many vendors and large POs with dozens of lines.

WITH THIS MODULE

Received qty shown on PO lines

Received Qty and quantity difference appear directly on purchase order lines. Instantly see which products arrived short, which are pending, and which are fully received — all without leaving the PO.

FEATURES

Complete receipt visibility on every PO
ORDERED

Ordered Quantity

The original ordered quantity is clearly displayed on each PO line for reference at a glance.
RECEIVED

Received Quantity Column

Total received quantity from all validated receipts shown directly on the purchase order line.
DIFFERENCE

Quantity Difference

Ordered minus Received shown as a variance. Negative values highlight shortfalls that need follow-up with the vendor.
PARTIAL

Partial Receipt Support

Multiple partial receipts are summed correctly. Always shows the true cumulative received quantity across all deliveries.
RFQ SUPPORT

Works on RFQs Too

Quantity columns visible on both Request for Quotation and confirmed Purchase Order views.
INSTANT

Zero Configuration

Install and columns appear immediately on all purchase order lines. No setup, no settings, no developer mode required.
